# Hossein Kashani — Portfolio

A responsive, static personal portfolio website designed for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository (for a user site, name it `YOUR-USERNAME.github.io`).
2. Upload `index.html`, `style.css`, and the `assets/` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Before publishing

- Confirm the LinkedIn profile URL in `index.html`. The current URL assumes the profile slug is `hossein-kashani`.
- Add project dates, employment dates, and more specific responsibilities only when you can verify them.
- The Docker project description intentionally states that the existing backend code was not authored by you.

No build tools or frameworks are required.
